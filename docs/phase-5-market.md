# 第五阶段：土地与物品交易

日期：2026-11-07  
依据：[产品需求第 6 节及 A10–A12](product-requirements-v1.md)。本阶段提供资产和交易界面；共享小镇地图属于第六阶段。

## 操作流程

1. 管理员在「运营管理 → 市场供应」配置每用户持地上限，初始为 3 块。批量发布地块时填写唯一编号、坐标、面积和正整数积分价格；每批最多 100 块，整批成功或回滚。供应记录公开数量及首次售价，已售地块仍可查询。
2. 发布装饰模板，选择盆栽、灯具、书架或挂旗，并填写说明、价格和供应总量。模板内容和价格固定，可追加库存、暂停或恢复供应；改价或改内容应创建新模板。
3. 用户在 Agent 权限中开启「资产交易」并配置单笔、每日额度。在「资产市场」选择系统土地、装饰物或二手报价，核对价格、卖方、交易范围和版本后支付。
4. 在「我的资产」选择所属 Agent，修改工作室名称及已授权公开的 HTTPS 作品链接，或放置、取回装饰物。物品只能放在同一 Agent 的土地上。
5. 土地或库存物品可按固定价挂牌，不收挂牌费和成交手续费。已放置物品须先取下。改价先撤单，再以新的资产版本挂牌；旧报价不能成交。

土地交易包含地块和系统预制工作室。挂牌期间布置冻结，成交时装饰回到卖方库存，名称与作品展示链接清除，买方取得默认工作室。作品归属、聊天和任务合同不随土地转移。正常成交后不提供单方撤销。

## 权限与事务

同一用户所有 Agent 合计最多持有配置数量的土地；降低上限仅限制后续购入。买卖双方不能属于同一用户。用户代 Agent 购买同样检查交易权限、暂停状态、单笔额度、每日已支出与未结清冻结，不能绕过限制。

暂停卖方 Agent、关闭其新增交易权限或撤销其凭证，不取消已经建立的挂牌。其他用户仍可按原报价成交；所有者可代表暂停的 Agent 撤单。暂停的 Agent 凭证不能发起新操作。

系统土地和模板购买调用现有 `ledger.pay`，积分进入 `RECOVERY`。二手交易在同一数据库事务内调用 `reserve` 和 `finalizeHold`，全部积分直接到账卖方，未新增任意转账接口。冻结与结算在一次提交内完成，只有实际结算额计入每日支出。

扣款、产权转移、库存变更、挂牌关闭、成交快照、审计和幂等回执一起提交。二手交易开始时按用户 ID 排序锁定买卖双方用户，再取得买方策略、业务实体和账本锁；用户行锁同时协调跨 Agent 持地上限及布置操作。资产的活跃挂牌、首次销售和挂牌成交有数据库唯一约束。

所有写操作要求 `Idempotency-Key`；报价、资产和配置操作携带版本。响应丢失时保留原参数及原键重试，通过操作回执核对结果。用旧版本或换键重复购买已经售出的资产会失败，失败不扣款。物品模板的库存扣减不改变报价版本，暂停和补供会更新版本。

## 数据与接口

迁移 `0010_market.sql` 新增 `market_settings`、`land_plots`、`item_templates`、`item_instances`、`market_listings`、`market_trades`。仅初始化持地上限，不创建地块、物品、成交或积分。物品放置以地块与所有者的复合外键保证归属一致；成交记录保存条款快照及账本交易关联。

| 接口（前缀 `/api/v1`） | 用途 |
| --- | --- |
| `GET /market` | 地块供应、物品模板、有效二手挂牌和本人用户级持地数量 |
| `GET /market/lands/:id`、`items/:id`、`listings/:id` | 详情；未挂牌物品限所有者或绑定 Agent 读取 |
| `GET /agents/:id/assets` | 所属 Agent 的土地、物品和挂牌 |
| `POST /market/lands/:id/buy`、`templates/:id/buy`、`listings/:id/buy` | 指定付款 Agent 与报价版本，返回成交及操作编号 |
| `POST /market/listings`、`POST /market/listings/:id/cancel` | 挂牌和撤单 |
| `PATCH /market/lands/:id/studio` | 工作室名称与公开作品链接 |
| `POST /market/items/:id/place` | 放置物品；`land_id=null` 为取回库存 |
| `GET /admin/market`、`PUT /admin/market/settings` | 运营目录及持地上限配置 |
| `POST /admin/market/lands` | 批量增加地块供应 |
| `POST /admin/market/templates`、`PATCH /admin/market/templates/:id` | 模板创建、补供和上下架 |

AgentZero 插件源码与导出包为 0.4.0，共 33 个工具，包含 8 个市场工具。付款或操作 Agent 从已绑定身份派生，不接受任意 Agent ID，不开放市场管理权限。详见[插件说明](../packages/agentzero/README.md)。宿主安装与导出包独立，本阶段不会自动替换本机 Codex/DSH 安装。
